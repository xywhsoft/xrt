# HTTP CORS Client Archive

该目录保存 2026-08-12 从 XRT 主线退出的浏览器式 CORS 客户端能力。

归档范围：

- Fetch safelist、响应字段可见性和非安全请求字段判定；
- 预检规划、预检请求字段写出和实际/预检响应校验；
- 按网络分区、Origin 和目标 URL 建立的线程安全预检缓存；
- 对应公共头、内部头、实现、模块测试、单头测试、示例和原始文档。

退出原因：

- CORS 是浏览器 Fetch 安全模型的一部分，不是通用 HTTP 客户端职责；
- 普通 C 客户端无法也不应模拟浏览器环境、网络分区和响应暴露策略；
- 预检缓存和客户端策略增加持久状态、同步依赖和发布体积，但不增强 HTTP 线缆底座；
- 这些能力适合作为独立扩展库，在需要浏览器语义模拟时显式依赖。

XRT 主线继续保留传输无关的 CORS 字段解析、服务端授权策略与直接响应字段写出：

- `http_cors`
- `http_cors_policy`
- `http_cors_write`

本目录不参与构建、单头文件生成、公开 API、测试覆盖率或发布体积统计。

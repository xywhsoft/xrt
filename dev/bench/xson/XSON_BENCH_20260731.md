# XSON 性能基线 2026-07-31

## 环境

- 系统：Windows 10.0.19045
- CPU：AMD Ryzen 5 5600 6-Core Processor
- GCC：16.1.0，`-O3 -std=c11`，x64
- TinyCC：0.9.27，`-O2 -m32`
- 输入：263 字节，包含 bytes、time、int-map、set、非有限浮点和 Unicode 转义
- 参数：每条路径 100,000 次

## 结果

| 编译器 | DOM 解析 | 解析吞吐 | 事件访问 | 访问吞吐 | DOM 写出 |
|---|---:|---:|---:|---:|---:|
| GCC x64 | 227,180 ops/s | 56.980 MiB/s | 731,459 ops/s | 183.462 MiB/s | 268,579 ops/s |
| TinyCC `-m32` | 47,443 ops/s | 11.899 MiB/s | 129,633 ops/s | 32.514 MiB/s | 62,105 ops/s |

两次运行的校验和均为 `76700000`。

## 解释

直接事件访问不构造 `xvalue` DOM，但仍严格解码 bytes、解析 time 并校验全部扩展
标签，因此它测量的是不含 DOM 分配和容器挂接的真实协议路径。写出包含 Base64
分块编码和 UTC 时间规范化。

本文件是同一机器、工具链、架构、输入和参数下的回归起点。解析与访问同时变慢
通常指向共享扫描、Unicode、Base64 或时间文本；只有解析变慢通常指向 Value 容器；
只有写出变慢通常指向 Value 遍历、格式化或 Buffer 增长。

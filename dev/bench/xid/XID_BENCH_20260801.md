# XID benchmark 2026-08-01

## 环境

- 平台：Windows x64
- 处理器：AMD64 Family 25 Model 33
- 编译器：GCC 16.1.0
- 参数：`-O3 -std=c11 -Wall -Wextra -Werror -m64`
- 迭代：200,000
- 批量大小：256

## 结果

| 路径 | ops/s |
| --- | ---: |
| 单个安全生成 | 11,755,163 |
| 批量安全生成 | 27,622,020 |
| 固定缓冲写入 | 10,721,101 |
| 严格解析 | 4,988,116 |
| 分配式格式化 | 4,985,057 |

`make` 包含每项一次系统安全随机调用与一次 `xrtNow`；`batch` 让 256 项共享一次安全随机调用，但仍逐项读取时间。批量吞吐约为单个入口的 2.35 倍，证明批量 API 能有效摊薄系统随机调用。

结果是当前机器的回归基线，不是跨硬件性能承诺。后续比较必须保持编译器、参数、迭代次数和系统负载一致。

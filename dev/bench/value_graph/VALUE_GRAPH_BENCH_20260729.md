# Value Graph 性能基线 2026-07-29

## 环境

- 系统：Microsoft Windows 10 专业版
- CPU：AMD Ryzen 5 5600 6-Core Processor
- GCC：16.1.0，`-O3 -std=c11`，x64
- TinyCC：0.9.27，`-O2 -m32`
- 参数：1,000 个独立 Object 节点；100 轮深克隆；1,000 轮大图相等；
  100,000 轮 24 层共享 DAG 相等；1,000,000 轮标量深克隆

## 结果

| 编译器 | 大图深克隆 | 大图结构相等 | 共享 DAG 相等 | 标量深克隆 |
| --- | ---: | ---: | ---: | ---: |
| GCC x64 | 2,214,500.995 nodes/s | 5,171,633.590 nodes/s | 889,881.601 ops/s | 22,939,199.651 ops/s |
| TinyCC `-m32` | 457,711.570 nodes/s | 913,015.798 nodes/s | 182,194.662 ops/s | 10,960,741.911 ops/s |

两次运行的校验和均为 `1201000`。

## 计量口径

- 大图深克隆与结构相等按每轮 1,000 个独立 Object 节点计数，不把根
  Array 和每个 Object 内的标量重复计入。
- 共享 DAG 每层含两条指向同一子节点的边；记忆表保证每轮只比较唯一值对，
  因而报告完整比较操作数，而不是展开后的理论边数。
- 标量深克隆只执行引用增加与释放，不创建身份表、不分配 Value 或 backing。

## 使用

本文件是同一机器、工具链、架构和参数下的回归起点。修改 Value 引用计数、
Map、内存池、身份表、递归深度或回调保护后应重新记录；跨机器绝对速率只
作为数量级参考。

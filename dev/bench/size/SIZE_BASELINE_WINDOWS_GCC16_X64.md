## 本轮收敛

与 2026-08-09 的旧开发基线相比：

- `http_websocket` 现在覆盖 HTTP 解码、WebSocket 握手、消息、压缩和解压的完整核心闭包；
  单头对象文件由旧版 1,013,547 降至 273,562 字节，减少约 73.0%。
- 同一完整闭包的静态库文件由旧版 1,020,902 降至 315,366 字节，减少约 69.1%。
- 迁出 WebSocket 连接层后，完整 `single/xrt.h` 由 8,350,240 降至 8,112,482 字节。
- `all` 单头对象文件由 4,386,332 降至 3,286,617 字节，减少约 25.1%。
- `all` 静态库文件由 5,133,800 降至 3,766,724 字节，减少约 26.6%。

旧基线保存在 `extlibs/xhttp/archive/original/baselines`，只用于后续扩展库复用和历史比较。


## 复现

```powershell
python tools\measure_size.py --compiler E:\software\w64devkit\bin\gcc.exe --arch x64 --baseline dev\bench\size\SIZE_BASELINE_WINDOWS_GCC16_X64.json --check
```

默认阈值为 `text` 10%、`data`/`bss` 20%、文件大小 15%。阈值只阻止未解释增长；任何
增长仍必须对应到功能或实现变化，不能通过覆盖基线隐藏。

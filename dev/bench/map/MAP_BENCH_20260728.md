# Map 性能基线 2026-07-28

## 环境

- 系统：Windows 10.0.19045
- CPU：AMD Ryzen 5 5600 6-Core Processor
- GCC：15.2.0，`-O3 -std=c11`，x64
- TinyCC：0.9.27，`-O2 -m32`
- 参数：1,000,000 个十进制文本键插入，10,000,000 次命中查询
- 容量：插入前执行 `xrtMapReserve(1000000)`

键格式为 `key-idx-%u`。插入和查询计时都包含 `snprintf`，与旧版 Dict 压力资产
保持同类工作量；结果不代表预构造二进制键的纯 Map 上限。

## 结果

| 编译器 | 插入耗时 | 插入速率 | 查询耗时 | 查询速率 |
| --- | ---: | ---: | ---: | ---: |
| GCC x64 | 186,360,400 ns | 5,365,946.843 ops/s | 1,313,010,900 ns | 7,616,083.004 ops/s |
| TinyCC `-m32` | 485,051,200 ns | 2,061,638.029 ops/s | 3,418,734,100 ns | 2,925,059.308 ops/s |

两次运行的校验和均为 `9785837073960166336`，每次查询同时验证返回值中的索引。

## 使用

本文件是同一机器、工具链、架构和参数下的回归起点。发布门禁应同时检查：

- 程序返回零，键数、每次查询和校验和全部正确。
- 没有未经解释的显著性能下降。
- 改变哈希、桶布局、键复制、堆分配或安全检查后重新记录结果。
- 跨机器结果只作参考，不直接套用绝对阈值。

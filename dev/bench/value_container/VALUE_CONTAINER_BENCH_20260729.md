# Value Container 性能基线 2026-07-29

## 环境

- 系统：Microsoft Windows 10 专业版
- CPU：AMD Ryzen 5 5600 6-Core Processor
- GCC：16.1.0，`-O3 -std=c11`，x64
- TinyCC：0.9.27，`-O2 -m32`
- 参数：1,000,000 次 Array 追加，200,000 次 Object 插入与查询，
  100 次 100,000 项 COW 分离，1,000 次 64 层共享 DAG 检查

## DAG 环检测

基准中的每一层都保存两次同一子容器。未去重的递归遍历会按路径数指数展开；
当前实现前 32 个唯一 backing 使用栈内地址去重，超出后才建立临时 Set。64 层图
因此按 65 个唯一 backing 访问，并保持可测的稳定吞吐。

## 使用

本文件是同一机器、工具链、架构和参数下的回归起点。改变 Value backing、COW、
Map/Set、环检测、引用计数或堆尺寸类后应重新记录结果。跨机器结果只作参考。

## 功能分组一

### `function_name`

一句话说明这个函数。

**功能：**

说明这个函数做什么，适合在哪个场景使用，不适合解决什么问题。

**函数原型：**

```c
XLLM_API int function_name(type *pArg, xllm_error *pError);
```

**参数：**

| 参数 | 方向 | 是否可为 `NULL` | 说明 |
| --- | --- | --- | --- |
| `pArg` | 输入 / 输出 | 否 | 参数含义、生命周期、所有权、有效范围 |
| `pError` | 输出 | 可选 | 失败时写入错误信息；调用者用 `xllm_error_free` 清理内部字符串 |

**返回值：**

- `0`：成功。
- 非 `0`：失败；如果传入 `pError`，错误码和消息写入 `pError`。

**资源归属：**

- 说明该函数是否分配资源。
- 说明调用者应该用哪个 reset/free/destroy 函数清理。
- 说明返回指针是借用还是调用者拥有。

**补充说明：**

- 调用顺序要求。
- 线程安全和重入注意事项。
- provider / scheme / profile 差异。
- 兼容性和版本注意事项。

**范例代码：**

```c
#include "xllm.h"

int main(void) {
    return 0;
}
```

# include

This directory is reserved for installed/public headers if `xwork` later adopts a packaged include layout.

For the current bootstrap stage, the canonical public header is:

- [xwork.h](/D:/git/xwork/xwork.h)

Do not copy `xwork.h` into this directory yet. The current supported source
layout is documented in [docs/PACKAGING.md](/D:/git/xwork/docs/PACKAGING.md).

# 类型队列

`typed_queue` 在 SPSC、MPSC 和 MPMC 有界指针队列上提供运行时类型值所有权。三种并发
角色分别由 `xtypedspscqueue`、`xtypedmpscqueue` 和 `xtypedmpmcqueue` 表达，不使用
运行时 `kind` 分派，也不会让只需要 SPSC 的构建引入 MPSC 或 MPMC 就绪队列。

## 存储与性能

初始化时一次性分配 `Capacity` 个按 `xrttype::Align` 对齐的值槽。入队从空闲环领取值槽，
调用类型 `Copy` 或 `Move` 后把槽地址发布到就绪环；出队把值移动到调用方已初始化输出，
再回收空槽。标量热路径在初始化完成后不执行 `xrtMalloc` 或 `xrtFree`。动态类型自己的
`Copy` 回调仍可按其语义分配内存。

请求容量向上取为底层队列支持的 2 次幂。SPSC 允许容量一；MPSC 和 MPMC 最小实际容量
为二。`Capacity` 固定到 `Unit`，不会在并发热路径扩容。

旧版 `xtqueue` 为每个元素分配包装内存，并在运行时切换四种队列实现。本模块保留其类型
值所有权、关闭后排空和字符串深复制能力，同时删除逐元素包装分配、引用计数对象和通用
`kind` 分派。可等待传递由 XRT 已有的 wait、channel 和任务层组合，本模块保持
SPSC、MPSC 与 MPMC 热路径无锁、无隐藏等待对象。

## 值契约

元素类型必须通过 `xrtTypeValidate`，占用非零存储、可复制，并具有自定义 `Move` 或
`TRIVIAL_COPY` 移动路径。类型不要求可重定位，因为固定值槽建立后不会移动地址。

`TryPush` 复制来源，成功后来源不变。`TryPushTake` 移动来源，成功后来源仍是已初始化
空值。`TryPop` 要求输出已经按同一类型初始化；成功时替换输出并把内部槽变为空值。
类型回调失败必须遵守 `runtime_type.md` 的失败原子合同。

来源、输出和批量连续值区间必须按元素类型对齐，不能与队列结构或内部值槽重叠。批量
操作的元素跨度是 `ItemType->Size`，输入输出应是该 C ABI 类型的连续数组。请求数为零
不要求数组地址非空。

类型回调不得重入同一个类型队列。不同线程可按对应队列角色并发执行回调，因此自定义
类型用于 MPSC/MPMC 时，其生命周期回调也必须满足相同并发要求。该限制避免给标量热
路径增加线程局部表或对象级串行锁。

## 结果与失败恢复

单元素操作复用 `xqueueresult`：`OK`、`EMPTY`、`FULL` 和 `CLOSED` 是正常流控，
`ERROR` 的结构化原因由 `xrtGetError` 取得。批量操作部分成功时返回 `OK` 和已处理前缀
数量；第一项未处理时保留具体流控或错误结果。

复制失败时空值槽会返回空闲池。移动出队失败时，SPSC/MPSC 由唯一消费者保留一个重试
槽，MPMC 放入并发重试环。后续出队先处理重试槽，所以失败不会像旧实现一样在原始指针
已经弹出后丢失元素。MPMC 多消费者中，某一元素移动失败后可由后续消费者重试；失败项
与其他已经被并发消费者领取的项之间不承诺完成顺序。

## 并发角色

- SPSC：一个生产者调用入队和关闭，一个消费者调用出队。
- MPSC：多个生产者调用入队，一个消费者调用出队。
- MPMC：多个生产者和多个消费者可同时操作。

关闭必须在阻止新生产者进入并等待已有生产者返回之后执行，与底层队列合同一致。关闭后
消费者继续排空，最终得到 `CLOSED`。`Count` 是就绪和重试元素的有界并发快照，不包含
正在类型回调中的临时槽，不能代替一次实际操作结果。

`IsDrained` 只有在写端关闭、可见元素为零且没有进行中的类型操作时才返回真。`Reset`
要求调用方独占且队列已排空，成功后复用原有值槽和指针环并重新开放。`Unit`、`Destroy`
和对象追踪同样要求独占。

MPSC/MPMC 的值槽在两个序列环之间转移。某个线程已经预留但尚未发布序列槽时，内部提交
可能短暂等待该前缀完成；这与底层序列环的进度合同一致，不代表公开队列已经达到容量。
类型回调和空闲槽领取仍在提交前完成，正常的 `FULL` 只由没有可领取值槽决定。

## 对象负载

三种 `TypeValidate` 和 `InstanceOps` 允许队列作为 XRT 引用对象负载。类型描述使用一个
元素泛型参数，并把 `Metadata` 指向 `xtypedqueuemeta`，其中 `Capacity` 决定实例的固定
容量。追踪在独占状态下访问全部已初始化值槽，空槽由元素类型的空值追踪语义自然忽略。

## 范例

可运行范例位于 `examples/runtime/typed_queue_spsc`、`typed_queue_mpsc` 和
`typed_queue_mpmc`。它们演示初始化、复制入队、移动出队和结束生命周期。

# BBRE 集成修改记录

XRegex 使用 BBRE 作为正则表达式执行核心。上游代码位于
`extlibs/xregex/src/third_party/bbre/`，许可证保存在同一目录。本文件只记录 XRegex
长期维护时必须保留的语义修改，不承担临时迁移进度跟踪。

## 捕获组克隆

原实现的 `bbre_clone()` 只复制编译后的程序，没有复制 `group_names`。带命名捕获组的
正则在克隆后会丢失捕获组名称和数量信息。XRegex 的版本会同时克隆名称表及其字符串，
并由捕获、克隆和故障分配测试覆盖成功与回滚路径。

## 分配器长度契约

命名捕获组字符串包含结尾空字符。释放这类字符串时，传给自定义分配器的旧长度必须为
`strlen(name) + 1`。XRegex 修正了少计算一个字节的问题，使严格分配器和内存调试器能够
准确核对分配与释放大小。

## XRT 适配边界

- BBRE 原始类型和入口只存在于第三方实现内部，不进入 XRegex 公共 API。
- XRegex 通过 `xrtMalloc`、`xrtRealloc` 和 `xrtFree` 接入 XRT 分配与故障注入体系。
- 查找、捕获和集合匹配保持薄适配，不为正常热路径额外创建临时结果容器。
- 公共错误、所有权、裁剪宏和线程规则由 XRegex 契约统一表达。

当前实现由 `extlibs/xregex/tests/regex/` 的模块测试、OOM 测试、单头测试和独立包消费者
共同验证。修改 BBRE 核心后必须同时运行这些门禁。

# xws 备份区

`xws` 承接从 XRT 核心退出的高级 WebSocket 客户端、服务器和 HTTP 适配能力。

当前 `archive/` 只保存第一阶段因 HTTP 依赖边界而退出核心的资产，不参与 XRT
构建。下一阶段会按与 HTTP 相同的原则重新评估和分层。

XRT 核心确定保留 WebSocket 帧、消息、握手、扩展协商、permessage-deflate 和可直接
组合网络/TLS 的高性能写入原语。当前仍在核心中的连接、Future 和分组层只作为已压实
资产暂留，下一阶段会继续判断哪些属于通用快速路径，哪些应迁入 xws；框架型客户端、
服务器、路由和便利对象不会回到 XRT 核心。

## 附：三份提示词共用的新预防检查（已纳入各防漂移段）

- 正文反引号奇偶扫描（ch141 类缺陷普防）：`sum(l.count('`') for l in
  正文行 if not l.strip().startswith('```')) % 2 == 0`，三语言全章 0 异常；
- 章号交叉引用有效性：`第 N 章 / Chapter N / глава N` 的 N 必须存在于
  order.json（当前基线：三语言 5,693 处引用 0 失效）；
- 三方对账：目录页 done 行数 = 磁盘 ch*.html 页数 = 状态行计数。

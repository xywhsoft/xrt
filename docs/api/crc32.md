# CRC32 校验和

`<xrt/crc32.h>` 提供 CRC-32/ISO-HDLC，也称 IEEE CRC32，采用反射多项式
`0xEDB88320`、初值和最终异或值 `0xFFFFFFFF`。这与 ZIP、gzip 的 CRC32
一致，不是 CRC32C。CRC32 只能检测非恶意损坏，不能用于密码、认证或防篡改。

## 裁剪与依赖

模块化构建选择 `crc32`；单头构建在包含 `xrt.h` 前定义 `XRT_MODULE_CRC32`。
本模块只依赖 core，不依赖压缩、文件或动态值。gzip 与 VFS pack 复用同一
内部算法和一份 64 字节只读表；第三方 ZIP 库的 CRC 实现不在本模块替换范围内。

## 稳定契约

长度以字节计，内嵌 NUL 和 UTF-8 均按原始字节处理，不调用 `strlen`。
空输入的校验和为零，空更新保持原 CRC；`NULL` 只允许配合零长度。
输入必须是调用期间可读的连续区域，无对齐要求。不保留指针，也不分配内存。
并发调用彼此独立；输入本身不能在读取时被并发修改。

空指针非零长度或地址范围回绕发布 `XERR_ARGUMENT` 并返回零。零也是合法
校验和，因此需要区分失败时应使用既有 XRT 错误边界；成功不会清除原有错误。
原生函数不能检测指针是否实际指向足够长的已分配区域，此条件由 C 调用者保证。

### 错误码总表

本模块使用通用错误种类，没有自定义错误域；通过 `xrtGetError()` 取得错误。

| 错误 | 触发条件 |
| --- | --- |
| `XERR_ARGUMENT` | 非零长度配合空指针，或地址范围回绕 |

### 线程约束与所有权

任意线程可调用，没有共享可变状态。输入为调用期间的借用，不接管、不持有，
也不修改；调用者负责避免并发写入。返回值是独立整数，不需要释放。

## 校验计算

### `xrtCrc32`

计算连续字节区域的 CRC32。

```c
uint32 xrtCrc32(const void* pData, size_t iSize);
```

#### 参数

| 参数 | 方向 | 约束 | 说明 |
| --- | --- | --- | --- |
| `pData` | 输入 | 零长度时允许空；存活到调用结束 | 连续可读字节区域，不修改内容 |
| `iSize` | 输入 | 字节数，区域须可读且地址不回绕 | 精确输入长度，NUL 不终止输入 |

#### 返回值

| 返回 | 含义 | 失败时状态 |
| --- | --- | --- |
| CRC 整数 | 32 位校验和，空输入为零 | 失败返回零，输入不变；错误由 `xrtGetError()` 取得 |

#### 错误

- `XERR_ARGUMENT` — 非零长度的空指针或地址范围回绕。

#### 范例

[CRC32 范例](../../examples/hash/crc32.c) 计算标准校验向量。

```c
uint32 crc = xrtCrc32("123456789", 9);
if (crc != UINT32_C(0xCBF43926)) return 1;
```

### `xrtCrc32Update`

从上一次最终化的 CRC 继续计算，任意分块与一次计算等价。

```c
uint32 xrtCrc32Update(uint32 iCrc, const void* pData, size_t iSize);
```

#### 参数

| 参数 | 方向 | 约束 | 说明 |
| --- | --- | --- | --- |
| `iCrc` | 输入 | 首次传零 | 先前公开函数返回的最终 CRC，不自行取反 |
| `pData` | 输入 | 零长度时允许空；存活到调用结束 | 新增的连续可读区域，不修改内容 |
| `iSize` | 输入 | 字节数，区域须可读且地址不回绕 | 本次新增区域的精确字节数 |

#### 返回值

| 返回 | 含义 | 失败时状态 |
| --- | --- | --- |
| CRC 整数 | 更新后的 CRC，空更新保持 `iCrc` | 失败返回零，输入与调用者保存的原 CRC 不变；错误由 `xrtGetError()` 取得 |

#### 错误

- `XERR_ARGUMENT` — 非零长度的空指针或地址范围回绕。

#### 范例

[CRC32 范例](../../examples/hash/crc32.c) 分两次计算相同校验和。

```c
uint32 incremental = xrtCrc32Update(0, "1234", 4);
incremental = xrtCrc32Update(incremental, "56789", 5);
if (incremental != crc) return 2;
```

# 模板设计

## 用途

模板模块将静态文本与调用方提供的数据组合成输出，适合生成配置、文本消息和受控的 HTML 片段。模板编译与渲染是分离的：可复用的已编译模板应在应用生命周期内保存，单次渲染使用独立上下文。

## 数据与输出

变量、循环和条件只读取调用方显式提供的数据上下文。渲染结果写入缓冲区或输出回调；调用方必须设置合理的输出上限，并处理缺失变量、表达式错误和容量不足。不要把模板解释结果当作可信命令、路径或查询条件，应在目标边界再次验证。

## HTML 安全

普通渲染保留原始文本，适用于任意文本格式。生成 HTML 文本节点时，请显式使用 HTML 渲染配置；它会转义 `&`、`<`、`>`、引号和撇号。该模式不自动处理 URL、JavaScript、CSS、属性名或已有 HTML 片段，应用必须为这些上下文采用专门的验证与编码策略。

## 并发与扩展

构造完成后不再修改的模板可以被多个渲染任务复用；每个任务仍需独立的渲染状态和输出。模板不隐式读取文件、网络或环境变量；需要包含文件、业务函数或缓存时，应由应用通过受控回调提供，并明确其错误和生命周期策略。

# XID 设计

## 用途

XID 是用于日志、对象引用和跨进程传递的紧凑标识符。它在本地生成，不依赖中心服务；标识符包含可排序的时间信息和随机性，适合大多数应用级唯一标识场景。

## 生成与表示

使用生成 API 创建 XID，使用格式化与解析 API 在二进制值和文本之间转换。文本格式应作为不透明标识符保存和比较，不要依赖其内部字段布局，也不要把它当作授权令牌或保密材料。

## 时间与排序

XID 的排序有助于按生成时间组织数据，但系统时钟回拨、跨主机时钟差和并发生成都会影响其与真实业务时间的严格对应关系。需要法律时间、全局事务顺序或可验证时间戳时，应使用专门的时间与一致性机制。

## 随机性与安全

随机部分降低碰撞概率，但 XID 不提供访问控制、不可猜测会话或加密保护。安全敏感令牌应使用密码学安全随机数并按独立的会话/密钥策略管理。解析外部 XID 时应检查格式错误，不要把无效输入静默转换为零值。

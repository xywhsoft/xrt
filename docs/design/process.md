# 进程设计

## 用途

进程模块用于启动子进程、传递参数与环境、连接标准输入输出，并等待、取消或终止执行。它适合受控的本地工具编排；不负责提供容器隔离、权限沙箱或跨主机调度。

## 参数与环境

优先使用参数数组和显式工作目录，而不是拼接一段 shell 命令。只有确实需要 shell 语义时才启动 shell，并把所有外部输入当作不可信数据。继承环境会带入代理、路径和敏感变量；需要可复现执行时，应显式构造最小环境。

## I/O 与生命周期

标准输入、输出和错误流可按管道方式连接。持续读取输出以避免子进程因管道缓冲写满而阻塞；对输出大小设置上限，避免不可信工具耗尽内存。启动成功不代表任务成功，调用方必须检查退出状态、取消状态和流错误。

## 取消与并发

取消或超时应先停止新的输入，再终止或请求子进程退出，最后持续回收输出和句柄。可变进程对象由一个控制流管理；若多个任务需要观察状态，应通过 Future、回调或调用方同步机制共享结果，而不是并发操作同一对象。

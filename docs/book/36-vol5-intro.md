## 导读

卷五回答"程序怎么与操作系统打交道"。前面的卷（容器/文本/数据）处理的是**进程内的世界**；本卷打开进程边界：日志（可观测性出口）、控制台（用户接口与降级）、IO 流（统一读写抽象与 Full 语义）、时间（时钟、时区与日历）、环境变量（配置最外层与三态）、路径与文件（持久化与安检）、目录与沙箱（组织、遍历与系统级边界）、异步文件（提交-完成模型与 Future）、信号（生命周期入口与观察者）。十四章按"观测、基础、持久化、高阶"的节奏展开，收官章（第 49 章）把故障注入、内存统计与日志串成调试诊断的联合作战管线。

### 本卷知识地图

```diagram flow
- 观测组：日志两章（Logger/Sink 分离）+ 控制台（流分流与降级）
- 基础组：IO 流抽象（Full 语义）+ 时间（微秒/UTC/日历）+ 环境变量（三态/分层）
- 持久化组：路径（词法/安检）+ 文件三章（句柄/映射锁原子/目录沙箱）
- 高阶组：异步文件（提交-完成/Future）+ 信号（观察者/三大入口）
- 收官：调试与诊断组合章——故障注入、统计、日志的联合作战
```

### 一条主线：边界纪律

比单个模块更重要的是贯穿本卷的**边界纪律**。进程边界是事故与攻击的交汇口——每章都在重复同一条哲学：**外部输入必过闸、输出必守约、跨越必显式**。路径章的 IsSafeEntry（穿越拒绝）、JSON 的三闸（第 32 章）、env 的三态显式、文件的 Full 语义（短读即失败）、信号的轻活回调——全是这条纪律的具体化。读完本卷你应该形成条件反射：**看到外部数据进来的第一反应是"闸在哪"，看到跨边界操作的第一反应是"契约是什么"**。

### 三条横切主题

第一条横切是**生命周期管理**（本卷密度最高的话题）：打开-使用-关闭的配对在本卷达到最高密度（文件句柄、目录流、映射、锁、观察者、异步句柄、任务池）——第 5 章的所有权语言在这里全面兑付；"Close 必查返回值"这类小纪律是它的末梢。第二条是**并发前奏**：异步文件的 Future、信号的并发回调、文件锁的多进程协调——本卷把并发的"原材料"备齐，卷六正式开工。第三条是**可观测性**：日志两章是主角，但控制台的流分工、env 的装配日志、时间的 UTC 纪律都是"为排障服务"的——收官章把它们统一成诊断工作流。

### 与前后卷的衔接

向前衔接：卷一的错误模型（本卷每个失败路径的骨架）、内存体系（句柄与缓冲的归属）、第 3 章资源边界（本卷两度上岗——目录深度与解压上限）。向后衔接：卷六的并发体系以本卷的 Future/任务池/信号为原材料开工；卷七网络引擎大量复用 IO 抽象与提交-完成模型；卷十二工程实践的构建/测试/部署三章，操作对象正是本卷的全部模块。**系统服务是"应用"与"操作系统"之间的翻译层**——本卷学完，你的程序从"算法容器"升格为"系统公民"。

### 三类读者三种走法

**服务端开发者**（主力读者）：全卷按序精读——日志/信号/优雅退出是你的日常，文件与路径是配置与持久化的载体；收官章的调试工作流直接进你的排障手册。**工具与 CLI 开发者**：重点读控制台（流分工与降级是你的用户体验底线）、路径（参数处理）、文件基础章；日志两章可用"最小装配"策略跳读。**嵌入式/资源受限开发者**：裁剪视角读——每章契约区的"零分配"与"资源边界"段落是你的重点；异步与映射按硬件能力取舍。三类读者共享同一条边界纪律——差异只在模块取舍的权重。

### 性能观：系统调用的经济账

本卷的性能主题是**系统调用的经济账**——用户态与内核态的每次跨越都有成本（微秒级），模块设计的多处"奇怪"其实都在省这笔账。目录枚举的"零额外 stat"（一次调用带出类型）是把 2N 省成 N；IO 的 Full 语义把重试循环收进库的同时也减少了往返；内存映射干脆取消逐次调用（页内访问零跨越）；异步文件的批量提交让 N 次 IO 在池上并行。看懂这本账，你就能自己判断"这里该缓存一次查询"还是"这里该合并调用"——第 107 章性能分析的文件与 IO 篇会带着测量工具回来精算。

### 一个提醒：本卷是"约定俗成"的解毒剂

Unix 五十年的文件、信号、终端约定是无数事故换来的智慧——但也以"口口相传"的方式毒害着新一代（谁没背过模式字符串密码、信号安全函数清单、行缓冲差异？）。本卷的每个模块都在做同一件事：**把口传智慧变成显式 API**——标志组合替代模式字符串、观察者替代受限处理函数、Full 语义替代循环样板、三态查询替代 NULL 歧义。学本卷时如果感到"这比我记忆中的传统做法简单"——那就是解毒生效；把简化背后的原坑也看一眼（各章的引入与坑区），你对系统的理解会比背清单的前辈更深一层。

### 学习检验（离开本卷前自测）

合上书回答七问：Logger 与 Sink 为什么分离、结构化字段比 printf 拼串强在哪？stdout 与 stderr 的分工红线是什么？Full 语义解决了什么样板？时间的三层视图（存储/运算/展示）各自纪律？文件三步收尾（临时-落盘-重命名）消灭了什么状态？异步的"受理≠完成"坑位在哪预防？信号回调为什么只能轻活？七问顺畅，卷五过关——含糊的回对应章节契约区重读；七问之外再加一个动手题：把卷四第 35 章的报告管线的输出端从 printf 换成本卷的日志系统（结构化字段 + 双 Sink + 轮转），你就完成了"数据处理 + 系统服务"两卷的第一次合体演练。
